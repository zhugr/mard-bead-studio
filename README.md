# MARD Bead Studio v2.2.5 · GitHub Pages Edition

## 这次更新
- 合并重复的「重新生成图片」和「重新生成三种方案」，现在只有一个「生成／重新生成拼豆图」按钮。
- 上传图片后会自动生成三个候选方案；修改设置后，点击唯一的生成按钮重新计算。
- 当任一候选经过手动编辑时，重新生成前会弹出确认提示，取消则保留当前作品。
- 没有已上传的原图时，按钮禁用（打开旧工程不会错误地重新生成）。
- 持续保留三种候选分别编辑、中文/English/BM、GitHub Pages、原有 JSON 工程兼容。
- 包含先前报告的 Dark Mode 统计卡片对比度修复。

## 更新步骤
将压缩包根目录中的 index.html、app.js、style.css、palette.js、README.md、.github 上传至现有 GitHub Repository 的相同路径并 Commit。不要清除浏览器网站数据；更新前建议导出作品备份。

## 注意
上传新图片会主动开始新的生成；已有候选的编辑保护提示适用于「重新生成」按钮。普通画布的编辑与工程打开不需要原图。
